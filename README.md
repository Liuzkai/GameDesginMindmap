# 游戏玩法点子集

这是一个用来收集、整理和沉淀游戏玩法/机制构思的仓库。每个点子彼此独立，不必属于同一款游戏；成熟到一定程度的点子可以单独拆出去成为正式项目。

维护约定见 [CODEBUDDY.md](CODEBUDDY.md)。新增点子请从 [`ideas/_template/idea.md`](ideas/_template/idea.md) 复制。
